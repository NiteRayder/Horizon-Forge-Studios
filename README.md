# Horizon Forge Studios

The public development website for **Horizon Forge Studios**, an independent software studio building software, community tools, games, and experimental technology across the **Silverline Network**.

## Website

The site is a lightweight static website built with HTML and CSS and hosted through GitHub Pages.

## Project directory

- **Horichan** — multipurpose Discord bot.
- **HORICHAN Sentinel** — companion web dashboard for Horichan.
- **Meridian** — custom browser project based on Mozilla Firefox and Gecko.
- **Orbit** — lightweight desktop environment concept.
- **Silverline Realms** — Minecraft project.

Some projects are still in planning or concept stages. See the website's [Projects](pages/projects.html) and [Roadmap](pages/roadmap.html) pages for the current overview.

## Local preview

Open `index.html directly in a browser, or serve the repository root with any simple static web server.
