HORICHAN Sentinel

A web dashboard for managing Horichan and its connected Discord servers from one central interface.

Purpose

HORICHAN Sentinel is the current name of the dashboard previously called GuildNexus. It is designed to work alongside Horichan rather than operate as a separate bot. Users should be able to authorize through Discord, choose a server they manage, and configure supported features from the browser.

Planned capabilities

Discord authorization

Use Discord OAuth and show servers available to the signed-in user.

Server configuration

Provide clear settings for supported bot features, with permission-aware access.

Operational visibility

Surface relevant status and activity information when the bot and backend provide it.

Development priorities

Current work centers on reliable navigation, responsive layouts, secure authorization, and a backend integration that returns data only for servers the user is permitted to manage. Features that require a live backend will not be represented as functional until connected and tested.
