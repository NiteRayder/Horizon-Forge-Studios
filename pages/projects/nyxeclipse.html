Horichan

A multipurpose Discord bot designed to help communities manage their servers through moderation, utility commands, automation, and integrations.

Project overview

Horichan is the current name of the Discord bot previously known as NyxEclipse. Development focuses on a dependable core, clear command behavior, maintainable modules, and practical server-management features.

Core areas

Moderation

Tools for applying server rules and helping moderators manage community activity.

Utilities

Useful commands and quality-of-life features for members and server staff.

Automation

Configurable workflows and integrations intended to reduce repetitive server tasks.

Companion dashboard

HORICHAN Sentinel is the companion dashboard project. It is intended to provide a web interface for server selection, configuration, and management, with access controlled through Discord authorization.

View HORICHAN Sentinel →

Technology

The bot is built with JavaScript and Discord.js, using the Discord API. Database and hosting choices may vary between hosted and self-hosted deployments.
