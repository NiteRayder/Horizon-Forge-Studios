Meridian

A custom browser project built around Mozilla Firefox and the Gecko platform, with an emphasis on a focused interface, customization, and practical browsing workflows.

From concept to implementation

Meridian evolves from the earlier Ecliptix concept. The project direction is to build on Mozilla's existing browser technology and reduce it to the components needed for the intended product, rather than attempting to create a browser engine from scratch.

Design priorities

Privacy and control

Make privacy-related behavior understandable and give users clear settings.

Customization

Develop a distinctive, streamlined interface without unnecessary visual clutter.

Maintainability

Keep upstream Gecko/Firefox components and licensing obligations in view as the project evolves.

Development status

The project is in its planning and foundation stage. Component selection, repository structure, build requirements, and a sustainable development workflow need to be established before a usable release can be promised.
